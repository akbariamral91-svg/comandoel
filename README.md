# کوماندوئل (Komandoel)

بازی مهمانی فارسی حدس و هوش — نسخه لاکچری طلایی و مشکی.

## مراحل راه‌اندازی (روی سیستم خودت)

### ۱. Flutter نصب کن
اگه هنوز نصب نکردی: https://docs.flutter.dev/get-started/install
بعد از نصب چک کن:
```
flutter doctor
```

### ۲. یک پروژه‌ی خالی Flutter بساز
```
flutter create komandoel
```
این کار پوشه‌های native اندروید/iOS (`android/`, `ios/`) رو می‌سازه که این ریپازیتوری آن‌ها را ندارد (چون این‌ها به سیستم‌عامل بستگی دارند و باید محلی ساخته شوند).

### ۳. فایل‌های این پروژه رو کپی کن
محتوای این ریپازیتوری (پوشه‌های `lib/`, `assets/`, و فایل `pubspec.yaml`) را داخل پوشه‌ی `komandoel` که در مرحله ۲ ساختی کپی کن (و فایل‌های پیش‌فرض `lib/main.dart` و `pubspec.yaml` که `flutter create` ساخته را جایگزین کن).

### ۴. فونت وزیرمتن (Vazirmatn) را دانلود کن
فایل‌های فونت در این پروژه گنجانده نشده‌اند (فقط پوشه‌ی خالی `assets/fonts/` وجود دارد). از گیت‌هاب رسمی دانلود کن:
https://github.com/rastikerdar/vazirmatn/releases

فایل‌های زیر را داخل `assets/fonts/` قرار بده:
- `Vazirmatn-Regular.ttf`
- `Vazirmatn-Medium.ttf`
- `Vazirmatn-Bold.ttf`
- `Vazirmatn-Black.ttf`

### ۵. نصب پکیج‌ها
```
flutter pub get
```

### ۶. اجرا برای تست
```
flutter run
```

### ۷. گرفتن APK
به‌صورت محلی:
```
flutter build apk --release
```
فایل خروجی: `build/app/outputs/flutter-apk/app-release.apk`

یا به‌صورت خودکار با GitHub Actions: کافیست این ریپازیتوری را روی GitHub push کنی؛ ورک‌فلوی `.github/workflows/build_apk.yml` به‌صورت خودکار روی هر push به شاخه‌ی `main` یک APK می‌سازد و آن را به‌عنوان Artifact قابل دانلود در تب Actions قرار می‌دهد.

## تاریخچه رفع باگ (بازبینی کامل کد)

پس از نوشتن نسخه‌ی اول، یک بازبینی کامل و دقیق روی کل کد انجام شد و باگ‌های زیر پیدا و اصلاح شدند:

1. **محاسبه‌ی نادرست سرعت جواب‌دادن** — امتیاز ۷/۵ بر اساس لحظه‌ای که راوی دکمه‌ی سبز را می‌زد محاسبه می‌شد، نه لحظه‌ای که واقعاً روی دایره‌ی بازیکن کلیک می‌کرد. حالا زمان دقیقاً در لحظه‌ی انتخاب بازیکن ثبت می‌شود.
2. **تایمر فاصله‌ی بین سوالات هنگام استپ متوقف نمی‌شد** — اگر راوی درست در فاصله‌ی ۳ ثانیه‌ای بین دو سوال دکمه‌ی استپ را می‌زد، سوال بعدی در پس‌زمینه (بدون توجه به استپ) ظاهر می‌شد. حالا این تایمر هم به‌درستی با استپ/ادامه هماهنگ است.
3. **کرش احتمالی هنگام انتخاب دستی راوی** — اگر راوی دستی انتخاب می‌شد و سپس تعداد بازیکنان کم می‌شد، برنامه موقع شروع بازی خطای Index خارج از محدوده می‌داد. رفع شد.
4. **پیام «برنده به دلیل کمترین اشتباه»** حتی در تساوی کامل (اشتباهات برابر) هم نمایش داده می‌شد. حالا فقط زمانی نشان داده می‌شود که واقعاً تعداد اشتباه کمتر بوده.
5. **انیمیشن «+امتیاز» برای مقادیر تکراری اجرا نمی‌شد** (مثلاً دو بار پشت‌سرهم ۷ امتیاز). حالا هر رویداد امتیاز شناسه‌ی یکتا دارد.
6. **همپوشانی احتمالی دکمه‌های سبز/قرمز با دایره‌ی بازیکن مجاور** در حالت تعداد بازیکن زیاد (۸ تا ۱۰ نفر) — فاصله‌ها اصلاح شد.
7. **چیدمان نامتقارن دکمه‌ی استپ** در نوار بالای صفحه بازی (قرار بود دقیقاً وسط باشد) — با استفاده از `Stack` به‌جای `Row` دقیقاً مرکز شد، و متن آن هنگام استپ‌بودن به «ادامه» تغییر می‌کند.
8. نشان کوچک راوی (میکروفون) روی دایره‌ی بازیکن راوی اضافه شد تا مشخص باشد چه کسی راوی است.

## صفحه‌ی بازی اکنون افقی (Landscape) است
طبق طراحی جدید، فقط صفحه‌ی «نمایش سوالات» به‌صورت افقی نمایش داده می‌شود (بقیه‌ی صفحات عمودی می‌مانند). این کار در کد به‌صورت خودکار انجام می‌شود: با ورود به این صفحه گوشی افقی می‌شود و با خروج دوباره عمودی می‌شود.

نکات مهم درباره‌ی این بخش:
- مختصات دقیق (گودی کاراکتر برای تایمر، حباب سوال، ابر جواب، دکمه استپ) بر پایه‌ی برآورد چشمی از روی عکس پس‌زمینه تنظیم شده‌اند. ممکن است بعد از اجرای واقعی روی گوشی نیاز به تنظیم جزئی (چند پیکسل جابه‌جایی) داشته باشند؛ اگر جایی هم‌راستا نبود، بگو دقیقاً کجا هست تا اصلاح کنم.
- ترتیب پرشدن ۱۰ جایگاه بازیکن (وقتی کمتر از ۱۰ نفر بازی می‌کنند) با تصمیم خودم انتخاب شده: ابتدا جایگاه‌های وسط بالا/پایین، بعد لبه‌ها، در آخر چپ/راست. اگر ترتیب دیگری مدنظرته بگو تا عوض کنم.
- مستطیل نام هر بازیکن (به‌جای دایره‌ی قبلی) هم اسم و هم امتیاز را با هم نشان می‌دهد.

### مختصات دقیق‌سنجی‌شده (پیکسلی، نه تخمین چشمی)
مختصات زیر با تحلیل برنامه‌ای رنگ‌های عکس اصلی (نه حدس بصری) استخراج شده و در کد به‌صورت نسبت (fraction) از عرض/ارتفاع صفحه استفاده می‌شوند تا روی هر سایز گوشی درست بمانند:

**صفحه بازی** (`bg_game_forest_landscape.png`, ۱۸۲۲×۸۶۳):
- گودی علامت‌سوال (تایمر): مرکز در (۲۹.۶٪ عرض, ۳۸.۲٪ ارتفاع)
- حباب سوال: از (۴۳.۵٪, ۲۷٪) تا عرض ۳۵.۶٪ و ارتفاع ۲۹.۷٪
- ابر جواب: از (۶۶.۳٪, ۶۷.۹٪) تا عرض ۲۰.۲٪ و ارتفاع ۱۷.۳٪

**صفحه پایان بازی** (`bg_result_forest.png`, ۱۶۷۲×۹۴۱):
- تابلوی اسم برنده: از (۱۶.۶٪, ۷.۹٪) تا عرض ۲۷.۵٪ و ارتفاع ۱۳.۹٪
- حلقه‌ی آواتار برنده: از (۲۰.۸٪, ۳۴.۹٪) تا عرض ۱۶.۱٪ و ارتفاع ۲۴.۴٪
- روبان امتیاز برنده: از (۱۷٪, ۵۹.۵٪) تا عرض ۲۳.۳٪ و ارتفاع ۱۱.۲٪
- کادر لیست بقیه‌ی بازیکنان: از (۵۱٪, ۲۳.۵٪) تا عرض ۳۷.۴٪ و ارتفاع ۶۰٪

⚠️ این مختصات با تحلیل پیکسلی دقیق به‌دست آمده‌اند، ولی چون امکان اجرای واقعی Flutter در این محیط نبود، بعد از اجرا روی گوشی واقعی حتماً چک کن که همه‌چیز درست روی عکس می‌نشیند؛ اگر جایی چند پیکسل جابه‌جا بود، دقیق بگو کجا تا اصلاح کنم.

**نکته‌ی جهت صفحه:** صفحه‌ی «بازی» و «پایان بازی» هر دو افقی (Landscape) هستند و برنامه به‌صورت خودکار موقع ورود/خروج از این دو صفحه جهت گوشی را عوض می‌کند. بقیه‌ی صفحات عمودی می‌مانند.

⚠️ هنوز عکس پنل‌های پارچمنتی صفحه‌ی ساخت محیط بازی (`panel_setup_parchment.png`) در کد استفاده نشده (چون تصمیم نهایی درباره‌ی طراحی آن صفحه با این عکس هنوز اعمال نشده).


## وضعیت فعلی / نکات باز برای فصل‌های بعدی
- نمایش برچسب دسته‌بندی سوال (`category`) در صفحه بازی فعلاً ساده است؛ طراحی نهایی (آیکون هر دسته و غیره) برای فصل بعد گذاشته شده.
- ویدیو/انیمیشن شخصیت میمون در پس‌زمینه صفحات هنوز اضافه نشده (طبق تصمیم مشترک، برای بعد از تکمیل هسته‌ی بازی گذاشته شده تا حجم برنامه سنگین نشود).
- افکت‌های صوتی (audioplayers در dependencies هست ولی فایل صوتی و اتصالش هنوز پیاده نشده).
